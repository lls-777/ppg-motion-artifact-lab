# 可穿戴 PPG 算法研究：心率、伪影识别与波形重建

> 作品展示草稿，2026-09-21。仅供私有仓库存档，公开范围待确认。本包含 4 篇文档和 4 张既有实验图；不含运行代码、数据、权重及完整评价文件，不能独立复现实验。

本项目围绕公开 PPG 数据，建立心率估计与质量筛选基线，复现 SMoLK，并研究 ACC 辅助滤波及残差网络的波形重建能力。
成果包括数据溯源、受控比较、模型计算核查和失败分析；目前尚未验证真实运动中的可靠逐搏波形恢复。

## 三阶段研究主线

| 阶段 | 研究问题 | 已有工作 |
|---|---|---|
| 自主基线 | 怎样计算心率，哪些窗口值得输出？ | 频谱/峰间心率、SQI、ACC 特征、冻结规则与受试者验证 |
| 论文复现 | SMoLK 能否复现，能否改善自己的心率筛选？ | 单种子复现、后处理核查、原始时间映射、相同覆盖率比较 |
| 波形重建 | 能否利用运动信息恢复可用波形？ | NLMS、门控、5393 参数残差网络、真实迁移评价、ACC 修正 |

SMoLK 只输出逐点伪影分数。V0/V1 的滤波器与 V2/V3 的残差网络才修改波形；它们是不同方法。

## 已完成研究的结果摘要

| 发现 | 对应证据与边界 |
|---|---|
| 三数据集 SMoLK Dice 接近论文表值 | seed 0，作者代码 151 点 SG；不是多种子统计复现 |
| 同覆盖率比较未支持 SMoLK 单独替代 SQI＋ACC | 各保留 1989/6744 窗；MAE 1.699 vs 1.920 bpm，大误差比例 0.452% vs 1.257% |
| 合成去噪有效，但真实逐搏可靠性未验证 | V2 的 0 dB NRMSE 1.000→0.554；真实峰间 HR MAE 11.323→13.024 bpm |
| ACC 预处理异常可定位、可验证 | 固定 V3 修正输入后，真实峰间 HR MAE 9.392→7.733 bpm |
| 一致性重训额外收益很小 | 峰间 MAE 7.733→7.692 bpm；identity 峰 F1 0.910→0.897 |

每一行只能在其对应实验内比较。不同版本的预处理、评价窗口和参考定义并不完全相同。

## 本项目新增的研究与工程工作

- 建立自主心率基线和质量筛选，并把论文模型接入具体下游任务。
- 将 3436 个训练段和 869 个测试段逐点匹配回原始受试者与时间。
- 核查后处理、指标和模型计算；保留与作者方法及代码的明确来源关系。
- 实现实际删核、参数导出和 NumPy 框架外回放；这些属于电脑端验证。
- 建立配对数据、划分、配置、逐窗指标和固定样例的追溯链，保留负结果。

SMoLK 模型设计归原作者。自建残差网络是研究原型，当前不主张新的通用算法或领先性能。
